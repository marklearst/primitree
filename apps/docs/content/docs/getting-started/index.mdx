This guide gets you from zero to a committed `design-tokens/` folder in a few minutes.

## 1. Install the CLI

```bash
npm i -D @figmavars/cli
# or run without installing
npx @figmavars/cli --help
```

## 2. Export variables from Figma

You need a `variables.json` file. On any Figma plan you can use a plugin export (TokensBrücke is a common choice), Dev Mode export, or copy from a teammate's backup.

Enterprise teams can also use:

```bash
export FIGMA_TOKEN=figd_...
figma-vars export --file-key AbCdEf... --out variables.json
```

See [Export variables](/docs/getting-started/export-variables) for every path.

## 3. Build the pipeline

```bash
figma-vars build variables.json
```

Default output directory: `design-tokens/`.

```bash
figma-vars build variables.json --out tokens --terrazzo
```

Use `--out` to change the folder. Use `--terrazzo` or `--style-dictionary` to pick a transformer config. Skip pieces with `--no-css`, `--no-tailwind`, `--no-ts`, and similar flags.

## 4. Commit the output

```bash
git add design-tokens variables.json
git commit -m "Add design token pipeline"
```

Keep the raw export in git if you want CI to diff against it on every PR.

## 5. Wire CI (optional)

The build scaffolds `design-tokens.workflow.yml`. Drop it into `.github/workflows/` and adjust paths. On each new export:

```bash
figma-vars diff backup/variables.json variables.json --fail-on-breaking
```

Exit code `2` means breaking changes. Good for PR gates.
