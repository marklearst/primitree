You need Node.js 24 or newer. Contributors working in this monorepo also need pnpm 11 or newer.

## 1. Install the CLI

```bash
pnpm add -D @figmavars/cli
# One-off command
npx @figmavars/cli --help
```

## 2. Export variables from Figma

Use the [FigmaVars Export plugin](/docs/figma-plugin) to download the local variables from the open file. FigmaVars also accepts supported JSON from another variables exporter.

Figma Enterprise organizations can call the Variables REST API:

```bash
export FIGMA_TOKEN=figd_...
figma-vars export --file-key AbCdEf... --out variables.json
```

See [Export variables](/docs/getting-started/export-variables) for the accepted input shapes.

## 3. Build the pipeline

```bash
figma-vars build variables.json
```

Default output directory: `design-tokens/`.

```bash
figma-vars build variables.json --out tokens --terrazzo
```

Use `--out` to change the folder. Use `--terrazzo` or `--style-dictionary` to pick a transformer config. The build reference lists each `--no-*` output flag.

## 4. Commit the output

```bash
git add design-tokens variables.json
git commit -m "Add design token pipeline"
```

Keep the raw export in git when pull requests need a semantic diff.

## 5. Wire CI (optional)

The build writes `design-tokens.workflow.yml`. Move the file into `.github/workflows/` and review its paths. The template rebuilds generated files after a push that changes `variables.json`.

Add this command to a pull request workflow for a breaking-change check:

```bash
figma-vars diff backup/variables.json variables.json --fail-on-breaking
```

With `--fail-on-breaking`, exit code `2` marks a breaking change.
