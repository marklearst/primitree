title: Overview
description: Typed React hooks for built design tokens or live Figma Variables API access.
---

```bash
npm install @figmavars/hooks react@^19.0.0 swr@^2.3.7
```

`@figmavars/hooks` requires Node.js 24 or newer and React `^19.0.0`.

The package has two data paths:

1. **Local tokens** read files from `figma-vars build`
2. **Live API hooks** read or change variables through the Enterprise Variables REST API with SWR

## Non-React usage

Framework-agnostic utilities live in `@figmavars/core` (normalizer, fetcher, diff). The `@figmavars/hooks/core` subpath keeps the existing re-export path.
