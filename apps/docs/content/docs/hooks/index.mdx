---
title: Overview
description: Typed React hooks for built design tokens or live Figma Variables API access.
---

```bash
npm i @figmavars/hooks swr react
```

Two modes:

1. **Local tokens (v5, any Figma plan)** consume artifacts from `figma-vars build`
2. **Live API (Enterprise)** read and mutate variables through the REST API with SWR

## Non-React usage

Framework-agnostic utilities live in `@figmavars/core` (normalizer, fetcher, diff). The `@figmavars/hooks/core` subpath re-exports them for backwards compatibility.
