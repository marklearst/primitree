---
title: Migration from @figma-vars/hooks
description: Replace @figma-vars/hooks with @figmavars/hooks v5.
---

FigmaVars v5 moves the hooks package from `@figma-vars/hooks` to `@figmavars/hooks`. The package requires Node.js 24 or newer, React `^19.0.0`, and SWR `^2.3.7`.

## Update the package

```bash
npm uninstall @figma-vars/hooks
npm install @figmavars/hooks
```

Change imports from `@figma-vars/hooks` to `@figmavars/hooks`. Documented hook, provider, utility, and type names keep their v4 names.

## New in v5

- `TokensProvider`, `useToken`, `useTokens`, `useTheme` for built DTCG artifacts
- Packages for core utilities, DTCG output, the CLI, and MCP now use the `@figmavars` namespace
- The CLI includes `build`, `diff`, `check`, `init`, and `export`

## Live API hooks

Update the dependency and imports, confirm the Node and React requirements, then run the application's tests.

## Adopt local tokens

1. Run `figma-vars build variables.json`
2. Import JSON + resolver in `TokensProvider`
3. Replace hard-coded colors with `useToken('path.to.token')`

## CLI bin

`figma-vars-export` remains in the hooks package as a compatibility bin. Use `@figmavars/cli` for `build`, `diff`, `check`, `init`, and `export`.

Read the [`@figmavars/hooks` changelog](https://github.com/marklearst/figmavars/blob/main/packages/hooks/CHANGELOG.md) for the release history.
