---
title: Semantic Diffing
description: figma-vars diff matches variables and reports breaking changes.
---

`figma-vars diff` matches collections, modes, and variables by their Figma IDs. A string diff cannot distinguish a rename from a removal followed by an addition.

## Rename detection

The same ID with a different name produces a rename. FigmaVars marks it as breaking because consumers may use the old path.

## Value changes

The same variable ID with a different raw `valuesByMode` entry produces a value change. The report labels the row with the current collection and mode name.

## Breaking vs non-breaking

**Breaking (exit code 2 with `--fail-on-breaking`):**

- Removed variables
- Renamed variables (path consumers may break)
- Variables moved between collections
- Variable type changes
- Removed or renamed collections
- Removed or renamed modes

**Reported without a breaking flag:**

- New variables
- New collections or modes
- Per-mode value changes
- Description changes

## Markdown output

Markdown is the default. Write it to a file for a pull request description:

```bash
figma-vars diff main/variables.json pr/variables.json --out PR_BODY.md
```

`--out <file>` writes the selected format to a file instead of standard output.

Use `--json` for machine-readable output:

```bash
figma-vars diff main/variables.json pr/variables.json --json --out diff.json
```

## MCP

The `diff_tokens` MCP tool accepts paths to an earlier and a later variables JSON file. It returns the same Markdown report.

## Library API

`diffVariables` and `formatDiffMarkdown` live in `@figmavars/core`. The normalizer converts supported input shapes before the comparison.
