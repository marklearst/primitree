---
title: CLI commands
description: Use the Primitree CLI to download Figma variables JSON, build token outputs, check sources, and explain tokens.
---

The CLI requires Node.js 24 or newer. Add it as a development dependency:

```bash
pnpm add -D @primitree/cli
```

Binary name: `primitree`.

## Commands

| Command   | Purpose                                            |
| --------- | -------------------------------------------------- |
| `build`   | Write token JSON, Resolver, CSS, Tailwind, and TS  |
| `diff`    | Semantic changelog between two exports             |
| `check`   | Check a DTCG source, Figma export, or token folder |
| `inspect` | Explain one token from a configured source         |
| `init`    | Create a token repository with sample data         |
| `export`  | Download variables via Figma REST API (Enterprise) |

```bash
primitree <command> --help
```

## Typical workflow

```bash
primitree init my-tokens
cd my-tokens
# replace variables.json with your export
npm install
npm run check
npm run diff
npm run build
```
