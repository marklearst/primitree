---
title: figma-vars export
description: Download local variables JSON from the Figma Variables REST API.
---

```bash
figma-vars export [options]
```

Figma limits the Variables REST API to Enterprise organizations. The request needs `file_variables:read` and access to the file.

## Usage

```bash
export FIGMA_TOKEN=figd_...
export FIGMA_FILE_KEY=your-file-key

figma-vars export --out variables.json
```

You can pass the file key while keeping the token in the environment:

```bash
figma-vars export --file-key "$FIGMA_FILE_KEY" --out variables.json
figma-vars export --fileKey "$FIGMA_FILE_KEY" --out variables.json
```

Use `--file-key` in new scripts. `--fileKey` remains as a compatibility alias.

## Options

| Option             | Description                                      |
| ------------------ | ------------------------------------------------ |
| `--file-key <key>` | Figma file key (or set `FIGMA_FILE_KEY`)         |
| `--fileKey <key>`  | Compatibility alias for `--file-key`             |
| `--out <path>`     | Output path (defaults to `figma-variables.json`) |

## After export

```bash
figma-vars build variables.json
figma-vars diff previous.json variables.json
```

The [FigmaVars Export plugin](/docs/getting-started/export-variables) reads local variables from the open file without calling the Variables REST API.
