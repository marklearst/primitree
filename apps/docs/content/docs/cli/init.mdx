---
title: figma-vars init
description: Scaffold a new design tokens repository with sample data or your own export.
---

```bash
figma-vars init [directory] [options]
```

## Usage

```bash
figma-vars init my-design-tokens
figma-vars init my-design-tokens --from ./exports/variables.json
```

Creates:

- `variables.json` (sample or copied from `--from`)
- the full generated token pipeline
- a `package.json` with build, check, diff, and backup scripts
- a GitHub Actions workflow in `.github/workflows/`

The initial pipeline is always generated during `init`.

## Options

| Option          | Description                                                     |
| --------------- | --------------------------------------------------------------- |
| `--from <file>` | Seed with your export instead of sample data                    |
| `--name <name>` | Set the project name (defaults to the destination directory)    |
| `--force`       | Replace scaffold-owned files while preserving unrelated content |

Good starting point for a dedicated tokens repo or a `packages/tokens` workspace in a monorepo.
