---
title: figma-vars build
description: Build a DTCG token pipeline from a Figma variables JSON export.
---

```bash
figma-vars build <variables.json> [options]
```

## Usage

```bash
figma-vars build variables.json
figma-vars build variables.json --out tokens --name "Acme DS"
figma-vars build variables.json --terrazzo --no-github-action
```

## Output

Writes a complete pipeline. See [Pipeline output](/docs/getting-started/pipeline-output) for the file tree.

## Options

| Option               | Default         | Description                      |
| -------------------- | --------------- | -------------------------------- |
| `--out <dir>`        | `design-tokens` | Output directory                 |
| `--name <name>`      | from file       | Resolver document name           |
| `--style-dictionary` | on              | Scaffold Style Dictionary config |
| `--terrazzo`         | off             | Scaffold Terrazzo config instead |
| `--no-transformer`   | off             | Skip transformer config          |
| `--no-css`           | off             | Skip `css/tokens.css`            |
| `--no-tailwind`      | off             | Skip Tailwind v4 file            |
| `--no-ts`            | off             | Skip TypeScript output           |
| `--no-github-action` | off             | Skip workflow template           |
| `--no-readme`        | off             | Skip generated README            |

## Programmatic use

The same logic lives in `@figmavars/dtcg`:

```ts
import { buildPipeline, type BuildPipelineResult } from '@figmavars/dtcg'

const result: BuildPipelineResult = buildPipeline(figmaJson, {
  transformer: 'style-dictionary',
})

for (const file of result.files) {
  console.log(file.path, file.contents)
}
```
