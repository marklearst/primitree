Open the playground at [/playground](/playground).

## Playground steps

1. Drop a `variables.json` file
2. Preview collections, modes, and resolved colors
3. Download the generated files as a zip

The page parses and builds the file in the current browser tab. It does not send the file to the FigmaVars server.

## CLI tasks

- CI and repeatable builds
- Output flags such as `--terrazzo` and `--no-tailwind`
- Writing generated files into a repository
- `diff` and `check` in PR workflows

The playground and [`figma-vars build`](/docs/cli/build) call `buildPipeline` from `@figmavars/dtcg` with the default options.
