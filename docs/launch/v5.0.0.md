# FigmaVars 5.0.0

Status: Unreleased.

FigmaVars 5 turns an exported Figma variables file into token files that can
live in a repository. The CLI writes DTCG 2025.10 plus a documented boolean
extension, Resolver contexts, CSS custom properties, a Tailwind CSS v4 theme,
TypeScript accessors, and transformer configuration.

## Release highlights

- `figma-vars diff` matches variables by stable Figma IDs. Renames keep their
  identity in the report, and `--fail-on-breaking` can gate CI.
- `@figmavars/hooks` reads built token artifacts for React themes. The package
  also keeps the live Variables REST API hooks.
- `@figmavars/mcp` lets MCP clients list, search, and resolve loaded tokens or
  compare two variables exports.
- `@figmavars/core`, `@figmavars/dtcg`, `@figmavars/cli`,
  `@figmavars/hooks`, and `@figmavars/mcp` share version 5.0.0.

## Requirements

- Node.js 24 or newer
- React `^19.0.0` and SWR `^2.3.7` for `@figmavars/hooks`

## Migration

The React package moved from `@figma-vars/hooks` to `@figmavars/hooks`. The
legacy npm package ends at version 4.0.0.

Read the [migration guide](https://figmavars.com/docs/hooks/migration) and the
[README](https://github.com/marklearst/figmavars/blob/v5.0.0/README.md).
