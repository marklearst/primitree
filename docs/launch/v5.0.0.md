# FigmaVars 5.0.0

FigmaVars 5 turns an exported Figma variables file into a versioned design
token pipeline. The CLI generates DTCG 2025.10 plus a documented boolean
extension, Resolver contexts, CSS custom properties, Tailwind CSS v4 themes,
TypeScript types, and transformer configuration.

## Release highlights

- `figma-vars diff` matches variables by stable Figma IDs and can fail CI on
  breaking token changes.
- `@figmavars/hooks` reads built token artifacts for runtime themes and keeps
  the live Figma API hooks for teams that use them.
- `@figmavars/mcp` lets MCP clients list, search, resolve, and compare the
  tokens in a project.
- The five public packages share version 5.0.0 under the `@figmavars` scope.

## Requirements

FigmaVars 5 requires Node.js 24 or newer. Start with the
[README](https://github.com/marklearst/figmavars/blob/v5.0.0/README.md) for
package and CLI examples.
