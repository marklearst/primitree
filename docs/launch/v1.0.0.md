# Primitree 1.0.0

Status: Unreleased.

Primitree checks a local DTCG source against the layer and owner rules in
`primitree.config.ts`. The CLI can inspect a token, compare two DTCG files with
configured rules, and build files for a repository. Configured builds can write a DTCG source
document, a Resolver document, CSS custom properties, a Tailwind CSS v4 theme,
TypeScript accessors, and a Primitree manifest.

## Release highlights

- `primitree check` reports findings for a configured DTCG source.
- `primitree inspect` shows one resolved token and its alias chain.
- `primitree diff` compares two DTCG files with configured rules. For Figma variables
  exports, it matches records by stable Figma IDs. Renames keep their identity
  in the report, and `--fail-on-breaking` can gate CI.
- `primitree build` writes the configured output files. Use `primitree build --check`
  to report missing, changed, and unexpected output files without writing.
- A Figma variables export is an optional input. Run `primitree build variables.json`
  to write DTCG 2025.10 plus a documented boolean extension,
  Resolver contexts, CSS custom properties, a Tailwind CSS v4 theme, and
  TypeScript accessors.
- `@primitree/hooks` reads built token artifacts for React themes. The package
  keeps the live Variables REST API hooks.
- `@primitree/mcp` lets MCP clients list, search, and resolve loaded tokens or
  compare two variables exports.
- `@primitree/core`, `@primitree/dtcg`, `@primitree/cli`,
  `@primitree/hooks`, and `@primitree/mcp` share version 1.0.0.

## Requirements

- Node.js 24 or newer
- React `^19.0.0` and SWR `^2.3.7` for `@primitree/hooks`

## Migration

The React package moved from `@figma-vars/hooks` to `@primitree/hooks`. The
legacy npm package ends at version 4.0.0.

Read the [migration guide](https://primitree.com/docs/hooks/migration) and the
[README](https://github.com/marklearst/primitree/blob/v1.0.0/README.md).
