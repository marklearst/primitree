# Primitree 1.0.0-next.0

Status: Partial release 2026-08-17. `@primitree/core` reached npm; five packages did not.

Primitree checks a local DTCG source against project layer and owner rules. The
first public prerelease also reserves the unscoped `primitree` package name, so
the complete CLI is available through one short command:

```sh
npx primitree@next check
```

The launcher forwards to `@primitree/cli`. It does not contain a second command
implementation or a separate configuration format.

## Release highlights

- `primitree check` evaluates a configured DTCG source and reports stable policy
  findings.
- `primitree inspect` traces one token through its alias chain, owners, and
  direct dependents.
- `primitree diff` reports token changes, affected aliases, and policy changes.
- `primitree build` writes DTCG, Resolver, CSS, Tailwind CSS, and TypeScript
  files. Its check mode reports drift without writing.
- `@primitree/hooks` reads generated token output in React applications.
- `@primitree/mcp` exposes loaded token graphs to MCP clients.
- The reviewed artifacts prepared all six packages at `1.0.0-next.0`. The
  attempt published `@primitree/core` and stopped before the other five.

## Prerelease channel

The package-family publication stopped after `@primitree/core` reached npm.
The other five packages and the GitHub Release were not published. npm assigned
both `next` and its required bootstrap `latest` to the core prerelease. The
reviewed `1.0.0-next.1` candidate supersedes this partial attempt.

## Requirements

- Node.js 24 or newer
- React `^19.0.0` and SWR `^2.3.7` for `@primitree/hooks`

## Migration

The React package moved from `@figma-vars/hooks` to `@primitree/hooks`. The
legacy npm package ends at version 4.0.0.

Read the [migration guide](https://primitree.com/docs/hooks/migration) and the
[README](https://github.com/marklearst/primitree/blob/v1.0.0-next.0/README.md).
