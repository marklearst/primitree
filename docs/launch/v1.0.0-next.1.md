# Primitree 1.0.0-next.1

Status: Released 2026-08-17.

Primitree checks a local DTCG source against project layer and owner rules. This
candidate completes the package-family prerelease after the `1.0.0-next.0`
attempt stopped after publishing `@primitree/core`.

```sh
npx primitree@next check
```

The unscoped launcher forwards to `@primitree/cli`. It does not contain a
second command implementation or a separate configuration format.

## Release highlights

- `primitree check` evaluates a configured DTCG source and reports stable policy
  findings.
- `primitree inspect` traces one token through its alias chain, owners, and
  direct dependents.
- `primitree diff` reports token changes, affected aliases, and policy changes.
- `primitree build` writes DTCG, Resolver, CSS, Tailwind CSS, and TypeScript
  files. Its check mode reports drift without writing.
- `@primitree/hooks` reads generated token output in React applications.
- `@primitree/mcp` exposes loaded token graphs to MCP clients.
- `primitree`, `@primitree/core`, `@primitree/dtcg`, `@primitree/cli`,
  `@primitree/hooks`, and `@primitree/mcp` share version `1.0.0-next.1`.

## Prerelease channel

Install this version through npm's `next` tag. npm may also assign `latest` to
a prerelease while a package has no stable version. `next` is the authoritative
prerelease channel, and stable `1.0.0` will establish the stable `latest` tag
after a separate review.

## Requirements

- Node.js 24 or newer
- React `^19.0.0` and SWR `^2.3.7` for `@primitree/hooks`

## Migration

The React package moved from `@figma-vars/hooks` to `@primitree/hooks`. The
legacy npm package ends at version 4.0.0.

Read the [migration guide](https://primitree.com/docs/hooks/migration) and the
[README](https://github.com/marklearst/primitree/blob/v1.0.0-next.1/README.md).
