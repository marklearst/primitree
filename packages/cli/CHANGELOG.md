# Changelog

## 5.0.0 (Unreleased)

Initial release of `@figmavars/cli`.

### Added

- `figma-vars build` for token files, Resolver contexts, CSS, Tailwind CSS v4, TypeScript, transformer configuration, and a workflow template.
- `figma-vars diff` for ID-based comparison between two variables exports.
- `figma-vars check` for variables exports and built token directories.
- `figma-vars init` for token repository scaffolding.
- `figma-vars export` for Enterprise Variables REST API access.
- Unsafe-path checks for scaffold and generated file writes.

### Requirements

- Node.js 24 or newer.
