Two ways to use it:

1. **Local-token hooks (v5, works on every Figma plan)** — consume the DTCG artifacts generated by [`figma-vars build`](https://www.npmjs.com/package/@figmavars/cli). No Personal Access Token, no network, SSR-safe.
2. **Live-API hooks (Enterprise)** — fetch and mutate variables through the Figma REST API with SWR caching.

```sh
npm i @figmavars/hooks swr react
```

## Local-token hooks (any plan)

Generate artifacts once (`npx @figmavars/cli build variables.json`), then:

```tsx
import { TokensProvider, useToken, useTokens, useTheme } from '@figmavars/hooks'
import primitives from './design-tokens/tokens/primitives.tokens.json'
import semantic from './design-tokens/tokens/semantic.tokens.json'
import semanticDark from './design-tokens/tokens/semantic.dark.tokens.json'
import resolver from './design-tokens/tokens/tokens.resolver.json'

export function App() {
  return (
    <TokensProvider
      tokens={{
        'primitives.tokens.json': primitives,
        'semantic.tokens.json': semantic,
        'semantic.dark.tokens.json': semanticDark,
      }}
      resolver={resolver}>
      <Toolbar />
    </TokensProvider>
  )
}

function Toolbar() {
  const brand = useToken('semantic.color.bg.brand')
  // brand.value  -> resolved DTCG value under the active contexts
  // brand.css    -> '#3366ff'
  // brand.cssVar -> 'var(--semantic-color-bg-brand)'

  const { contexts, availableContexts, setContext } = useTheme()
  return (
    <button
      style={{ background: brand.css ?? undefined }}
      onClick={() => setContext('semantic', contexts.semantic === 'dark' ? 'light' : 'dark')}>
      Theme: {contexts.semantic}
    </button>
  )
}
```

- `TokensProvider` accepts a single DTCG document, an array (merged in order), or the file map + resolver from `figma-vars build`.
- `useToken(path)` resolves `{references}` under the active contexts and re-renders on theme switches.
- `useTokens()` returns every flattened token with resolved values.
- `useTheme()` reads and switches resolver contexts — a Figma collection "Theme" with modes Light/Dark becomes `setContext('theme', 'dark')`.

## Live-API hooks (Enterprise)

Requires a Full seat in an Enterprise org and a token with `file_variables:read` (and `file_variables:write` for mutations).

```tsx
import { FigmaVarsProvider, useVariables, useUpdateVariable } from '@figmavars/hooks'

function App() {
  return (
    <FigmaVarsProvider
      token={process.env.FIGMA_TOKEN}
      fileKey='your-file-key'>
      <VariablesDashboard />
    </FigmaVarsProvider>
  )
}

function VariablesDashboard() {
  const { data, isLoading, error } = useVariables()
  const { mutate: update, isLoading: saving } = useUpdateVariable()
  // update({ variableId, payload: { name: 'color/bg/brand' } })
}
```

**Query hooks** — `useVariables`, `usePublishedVariables`, plus selectors `useVariableCollections`, `useVariableModes`, `useVariableById`, `useCollectionById`, `useModesByCollection`.

**Mutation hooks** — `useCreateVariable`, `useUpdateVariable`, `useDeleteVariable`, `useBulkUpdateVariables`, each returning `{ mutate, data, error, isLoading, isSuccess, isError }`, and `useInvalidateVariables` to refresh SWR caches after writes.

**Auth/context** — `useFigmaToken`, `useFigmaTokenContext`.

### Offline / fallback mode

No Enterprise seat? Feed the provider a variables JSON export and every read hook works against it:

```tsx
<FigmaVarsProvider token={null} fileKey={null} fallbackFile={variablesJson}>
```

### Error handling and retries

```ts
import { isFigmaApiError, isRateLimited, getRetryAfter, withRetry } from '@figmavars/hooks'

const fetchWithRetry = withRetry(() => fetcher(url, token), {
  maxRetries: 3,
  retryOnlyRateLimits: true, // respects Retry-After on 429s
})
```

### SWR configuration

```tsx
<FigmaVarsProvider token={token} fileKey={key} swrConfig={{ refreshInterval: 30_000 }}>
```

## Non-React usage

Everything framework-agnostic lives in [`@figmavars/core`](https://www.npmjs.com/package/@figmavars/core) (typed `fetcher`/`mutator`, normalizer, alias resolution, diffing). The `@figmavars/hooks/core` subpath re-exports it for backwards compatibility.

## CLI export

This package still ships the `figma-vars-export` bin; the full-featured CLI (`build`, `diff`, `check`, `init`, `export`) is [`@figmavars/cli`](https://www.npmjs.com/package/@figmavars/cli).

## Migrating from 4.x

Replace `@figma-vars/hooks` with `@figmavars/hooks` in dependencies and imports. Documented API names are unchanged — see the [CHANGELOG](CHANGELOG.md#500-unreleased) for details and the full v5 story.
